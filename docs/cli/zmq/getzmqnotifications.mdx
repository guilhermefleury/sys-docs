# `getzmqnotifications`

Returns information about the active ZeroMQ notifications.

## Synopsis

```
getzmqnotifications
```

## Result

```
[                            (json array)
  {                          (json object)
    "type" : "str",          (string) Type of notification
    "address" : "str",       (string) Address of the publisher
    "addresssub" : "str",    (string, optional) Address of the subscriber, omitted if there is no subscriber assigned to this notification
    "hwm" : n                (numeric) Outbound message high water mark
  },
  ...
]
```
