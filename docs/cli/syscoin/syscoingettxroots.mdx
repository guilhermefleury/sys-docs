# `syscoingettxroots`

Get NEVM transaction and receipt roots based on block hash.

## Synopsis

```
syscoingettxroots "blockhash"
```

## Arguments

```
1. blockhash    (string, required) The block hash to lookup.
```

## Result

```
{                           (json object)
  "txroot" : "hex",         (string) The transaction merkle root
  "receiptroot" : "hex"     (string) The receipt merkle root
}
```

```
> syscoin-cli syscoingettxroots 0xd8ac75c7b4084c85a89d6e28219ff162661efb8b794d4b66e6e9ea52b4139b10
```
