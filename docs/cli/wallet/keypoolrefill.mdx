# `keypoolrefill`

Fills the keypool.
Requires wallet passphrase to be set with walletpassphrase call if wallet is encrypted.

## Synopsis

```

```

## Arguments

1. newsize    (numeric, optional, default=1000, or as set by -keypool) The new keypool size
