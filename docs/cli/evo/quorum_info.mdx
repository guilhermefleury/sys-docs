# `quorum_info`

Return information about a quorum

## Synopsis

```
quorum_info "quorumHash" ( includeSkShare )
```

## Arguments

```
1. quorumHash        (string, required) Block hash of quorum.
                     
2. includeSkShare    (boolean, optional, default=false) Include secret key share in output.
```

## Examples

```
> syscoin-cli quorum_info 1075db55d416d3ca199f55b6084e2115b9345e16c5cf302fc80e9d5fbf5d48d
```
